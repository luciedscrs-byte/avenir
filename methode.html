Étape 2 · Comment j'ai fait

Comment j'ai mis en place la recherche

Un petit programme interroge chaque jour les offres d'emploi, les enregistre, et ce site les affiche. Tout tient en quatre blocs.

Le schéma, de la clé API au site

Quatre blocs, de gauche à droite : la clé obtenue chez France Travail sert à mon script, que GitHub lance ensuite tous les jours à ma place.

1. France Travail

1 Compte développeur

2 Abonnement à l'API « Offres d'emploi v2 »

3 Clé : identifiant + secret

2. Mon ordinateur

4 Fichier .env : la clé reste chez moi

5 Script Python : demande les offres du code M1620

3. GitHub

6 Dépôt public : le code et les données

7 Secrets : la clé y est cachée

8 Action : lance le script chaque jour, sans mon ordinateur

4. Le site

9 Fichiers du jour enregistrés

10 GitHub Pages : le site s'affiche

Les cinq maillons, expliqués en une phrase
1

Choisir le métier

Je choisis un code ROME, qui classe chaque métier chez France Travail (M1620 pour l'assistant marketing), et des mots-clés pour les postes de responsable.

Métierscope
2

Obtenir l'accès

Je crée un compte développeur France Travail. Il me donne une clé (des identifiants) qui m'autorise à interroger les offres.

API France Travail
3

Récupérer les offres

Un script interroge l'API et enregistre les offres du jour dans un fichier daté. Un autre croise les entreprises de data.gouv.

Python
4

Automatiser

GitHub lance le script tout seul chaque jour, sans que mon ordinateur soit allumé, et sauvegarde le résultat. Mes clés sont cachées dans ses « secrets ».

GitHub Actions
5

Afficher

Ce site, hébergé gratuitement, lit les fichiers et affiche les chiffres : il se met à jour sans que je touche à rien.

GitHub Pages

Ce que ça donne

Pour vérifier : l'onglet « Actions » du dépôt GitHub montre une exécution verte par jour, et l'onglet « commits » un enregistrement par jour signé « veille-bot ».

Ce que j'ai respecté

Des sources officielles

Uniquement des API publiques (France Travail, data.gouv, geo.api.gouv). Aucune copie de LinkedIn, de l'Apec ou d'Indeed.

Aucune donnée personnelle

Le site ne contient que des données sur les offres et les entreprises, aucun nom de personne (règle RGPD).

Des clés protégées

Mes identifiants ne sont jamais écrits dans le code : ils restent dans les « secrets » de GitHub.

Pour aller plus loin : le détail technique

Le dépôt GitHub contient les scripts (dossier scripts), les fichiers de données datés (dossier data) et ce site. Le README explique chaque fichier, les sources, les limites et la règle de comptage des offres. L'automatisation demande 7 h, mais GitHub l'exécute en pratique entre 11 h et 16 h, car il retarde les tâches planifiées quand il est chargé.
