Comment ce site est fabriqué

Rien n'est saisi à la main : un robot refait le travail tous les jours, sans mon ordinateur.

1. Il interroge

Chaque jour, GitHub lance des scripts qui interrogent l'API officielle de France Travail et celle des entreprises (data.gouv.fr).

2. Il enregistre

Les résultats sont ajoutés au dépôt en fichiers datés : l'historique devient l'archive du marché.

3. Il affiche

Ce site, hébergé gratuitement sur GitHub Pages, lit ces fichiers. Aucun serveur, aucune donnée personnelle, aucun scraping.
