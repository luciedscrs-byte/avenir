Limites de ces chiffres

  • Un seul canal : l'API France Travail « Offres d'emploi v2 ». Les offres publiées uniquement ailleurs n'y sont pas.
  • La Bonne Alternance reprend des offres France Travail : les deux canaux se recoupent en partie, et le recoupement exact reste à établir.
  • Les entreprises du haut de classement publient parfois la même annonce plusieurs fois : le nombre d'offres n'est pas le nombre de postes.
  • Le code ROME M1620 regroupe des intitulés proches mais pas identiques (assistant marketing, assistant commercial, chef de produit junior…).
